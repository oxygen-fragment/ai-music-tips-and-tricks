# Song Structure

The blueprint of how a song is organized. Most songs follow predictable patterns.

## Core Components

### Verse

The storytelling section. Sets the scene, develops the narrative.

#### Verse Characteristics

- Lyrics usually change each time
- Lower energy than chorus (typically)
- Builds tension toward chorus
- Usually 2-4 verses per song

#### Example structure

```
Verse 1: Introduce situation
Chorus: Main message
Verse 2: Develop the story
Chorus: Repeat main message
```

**In AI prompts:** `[verse]` or `[verse 1]`, `[verse 2]`

---

### Chorus

The hook. The part everyone remembers and sings along to.

#### Chorus Characteristics

- Same lyrics every time (usually)
- Highest energy
- Contains the song's main message
- Most catchy/memorable part
- Repeats 2-4 times in song

#### Common patterns

- Verse → Chorus → Verse → Chorus
- Verse → Pre-chorus → Chorus (builds anticipation)

**In AI prompts:** `[chorus]` or `[hook]`

---

### Bridge

The "different" section. Breaks the pattern.

#### Bridge Characteristics

- Usually appears only once
- Different melody/chords from verse and chorus
- Provides contrast or new perspective
- Often appears after 2nd chorus, before final chorus
- Can be higher or lower energy

#### Why it exists

Prevents song from feeling repetitive.

#### Typical placement

```
Verse 1 → Chorus → Verse 2 → Chorus → Bridge → Chorus
```

**In AI prompts:** `[bridge]`

---

### Pre-Chorus

The build-up section before the chorus hits.

- Shorter than verse (usually 4-8 bars)
- Builds tension/anticipation
- Makes chorus hit harder
- Different from verse but leads into chorus smoothly

**Energy flow:**

```
Verse (medium) → Pre-Chorus (building) → Chorus (peak)
```

**In AI prompts:** `[pre-chorus]` or `[pre chorus]`

---

### Intro

The beginning. Sets the mood before vocals start.

**Characteristics:**

- Usually instrumental (no vocals)
- 4-8 bars typical length
- Establishes tempo, key, vibe
- Can be simple or complex

**Common types:**

- Instrumental version of chorus melody
- Atmospheric build
- Signature riff/hook
- Minimalist (single instrument)

**In AI prompts:** `[intro]` or let AI generate naturally

---

### Outro/Coda

The ending. How the song finishes.

**Characteristics:**

- Can fade out or have definite ending
- Often repeats chorus or hook
- Sometimes introduces new element
- May return to intro theme (bookend)

**Common types:**

- Fade: Volume gradually decreases
- Cold ending: Sudden stop
- Ritardando: Gradually slows down
- Extended: Long instrumental finish

**In AI prompts:** `[outro]` or `[ending]`

---

## Common Song Structures

### Pop Standard (ABABCB)

```
Intro → Verse → Chorus → Verse → Chorus → Bridge → Chorus → Outro
```

**Used in:** Most pop, rock, country

---

### Simple Verse-Chorus (ABAB)

```
Intro → Verse → Chorus → Verse → Chorus → Outro
```

**Used in:** Punk, some pop, shorter songs

---

### Extended Pop (ABABCBB)

```
Intro → Verse → Chorus → Verse → Chorus → Bridge → Chorus → Chorus → Outro
```

**Used in:** Power ballads, anthems (repeat chorus for emphasis)

---

### AABA (Classic/Jazz)

```
Verse 1 → Verse 2 → Bridge → Verse 3
```

**Note:** No distinct chorus. Last verse often varies.
**Used in:** Jazz standards, older pop, some Beatles songs

---

### Through-Composed (No Pattern)

```
Section A → Section B → Section C → Section D...
```

**Note:** Each section is different. No repeats.
**Used in:** Progressive rock, classical, experimental

---

## AI Prompting Tips

**Explicit structure:**

```
[intro]
[verse]
Lyrics here
[chorus]
Lyrics here
[verse]
More lyrics
[chorus]
Repeat
[bridge]
Different part
[chorus]
[outro]
```

**Let AI decide structure:**

```
"Upbeat pop song about summer" + lyrics
(AI will structure automatically)
```

**Specify if you want variation:**

```
"Song with extended bridge section"
"No chorus, AABA structure"
"Two verses before first chorus"
```

---

## Experiments to Try

1. **Same lyrics, different structures:**
   - ABAB vs ABABCB with identical lyrics
   - Notice how bridge changes the feel

2. **No chorus song:**
   - Use only verses (AABA structure)
   - See how repetition works differently

3. **Double bridge:**
   - Add two bridges instead of one
   - Creates unusual but interesting flow

4. **Intro = Outro:**
   - Use same musical idea for both
   - Creates satisfying bookend effect
