# Harmony

Supporting notes that make the melody richer. Multiple notes played together.

**Think of it as:** Background singers or chord progressions that fill out the sound.

**Examples:**

- Choir singing different notes simultaneously
- Guitar chords under a vocal melody
- Bass note + melody note = harmony

**Simple test:** If you can hum it easily, it's probably melody. If it's the "other notes" making it sound full, that's harmony.
