# Crescendo / Diminuendo

**What it is:**

- Crescendo: Gradually getting louder
- Diminuendo (or Decrescendo): Gradually getting quieter

**Think of it as:** Volume fades, but done intentionally for effect.

**Why use it:** Build tension (crescendo) or wind down (diminuendo).

**In AI prompts:**

- "Building intensity"
- "Gradual fade out"
- "Explosive build-up"
