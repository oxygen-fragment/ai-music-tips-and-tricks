## How to Contribute

### Submission Guidelines

Want to share your creation? We'd love to feature it!

**What to include:**

1. **Audio Link** - Link to your track (Suno, Udio, SoundCloud, etc.)
2. **Platform Used** - Which AI tool and version
3. **Prompt/Setup** - Share your prompt or technique
4. **Techniques Used** - Reference guide sections you used
5. **What Worked** - What went well
6. **What Didn't** - Any challenges or failures
7. **Settings** - Any relevant platform settings
8. **Your Name/Credit** - How you'd like to be credited

**Optional but awesome:**

- Waveform screenshot
- Iteration history (what you tried before this worked)
- Comparison audio (before/after tweaks)

### How to Submit

**Option 1: GitHub Issue**

- [Open a Community Example issue](https://github.com/oxygen-fragment/ai-music-tips-and-tricks/issues/new)
- Use the template
- We'll review and add to this page

**Option 2: Pull Request**

- Add your example to this file
- Follow the format below
- Submit PR

### Example Entry Format

```markdown
### [Track Title]

**Artist/Creator:** Your Name (@username)
**Platform:** Suno v5.0
**Genre:** Melodic Trap
**Link:** [Listen Here](https://example.com/track)

**Techniques Used:**
- [Trap Tempo Paradox](../samples/beats/trap.md#the-trap-tempo-paradox)
- [Meta Tags for instrumentation](platforms/suno-tags.md#instrumentation-description)

**Prompt:**
\`\`\`
70 BPM melodic trap with pitched 808 slides
[Instrumentation: Piano, 808 bass, rolling hi-hats]
[Mood: Dark, introspective]
\`\`\`

**Settings:**
- Weirdness: 40%
- Style Influence: 75%

**What Worked:**
Specifying 70 BPM prevented the AI from making the kick pattern too fast. The pitched 808 slides came through clearly.

**Challenges:**
Initially tried 140 BPM and got completely wrong rhythm. Reducing to 70 BPM fixed it immediately.

**Tips for Others:**
Always use the actual tempo for trap (70-80 BPM), not the perceived tempo.
```
